Which one?

用途が近い窓口の選び方

support と info
Botやサービスの使い方・不具合は support、法人取引や提携などそれ以外の一般的な相談は info へ。
billing・tokuho・legal
実際の請求・決済・返金は billing、特定商取引法に基づく表記や販売条件は tokuho、規約・契約・権利に関する内容は legal へ。
privacy と security
個人情報の開示・訂正・削除などの請求や取り扱いの質問は privacy、脆弱性や漏えいの恐れなど安全性の問題は security へ。

どの窓口か判断できない場合は、総合窓口（info@disnana.com）へご連絡ください。

メンバーの一覧は公式メンバーのページでご確認いただけます。お問い合わせは、メンバー個人ではなく上記の窓口へお願いします。
